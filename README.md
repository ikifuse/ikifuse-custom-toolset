# ikifuse Custom Toolset

AI協働開発で繰り返し使うプラグイン、スキル、ルーティン、テンプレート、判断基準などを、一か所にまとめて管理する個人用ツールセットです。

困り事ごとに道具を小さく独立させ、必要なものだけをプロジェクトへ導入できる形を目指しています。

このツールセットは、道具を増やし続けることを目的としていません。困り事やAIの進化に合わせて道具を追加・見直しし、必要でなくなったものは統合・保管・削除しながら、その時点で役立つものだけを残していきます。

## このツールセットで実現したいこと

- 困り事ごとに小さな道具を追加できる
- 必要なものだけを個別に導入・有効化できる
- 不要なものを個別に無効化・取り外しできる
- 一つを修正しても、他の道具へ影響しにくくする
- GitHubで全体の構成と中身を一覧できる
- 新しいプロジェクトでも同じ道具を再利用できる
- 外部で見つけた道具を、出所を残して保管できる
- 将来、役に立ったものだけを他の人やチームへ渡せる

## 全体構成

```text
ikifuse-custom-toolset/
├── README.md
├── 説明書/
├── 共通/
├── OpenAI・Codex用/
├── Google・Antigravity用/
├── 外部から導入したもの/
└── .agents/
```

| 場所 | 内容 |
|---|---|
| [説明書](説明書/) | 使い方、管理方法、よくある質問、個人・チームでの活用 |
| [共通](共通/) | 特定のAI環境だけに依存しないルーティン、テンプレート、判断基準、過去の事例 |
| [OpenAI・Codex用](OpenAI・Codex用/) | Codexで使うプラグイン、単体スキル、専用設定 |
| [Google・Antigravity用](Google・Antigravity用/) | Antigravityで使うスキル、ワークフロー、専用設定 |
| [外部から導入したもの](外部から導入したもの/) | 他の人や公開リポジトリから導入した道具 |

## 基本的な使い方

1. 「現在入っている道具」または分類フォルダから、使いたい道具を探します。
2. 各道具のREADMEで、対象環境、導入方法、使い方、制約を確認します。
3. 必要な道具だけを対象のAI環境へ導入します。

詳しい使い方や管理方法は、[説明書](説明書/)にまとめています。
