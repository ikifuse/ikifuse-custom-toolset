# ikifuse Custom Toolset

AI協働開発で繰り返し使うプラグイン、スキル、ルーティン、テンプレート、判断基準をまとめる個人用ツールセットです。

困り事ごとに小さく追加し、不要になったものは個別に外せる形で管理します。新しいプロジェクトでも同じ道具を再利用でき、将来は役に立ったものだけを他の人へ渡せる構成を目指します。

## 管理ルール

- 人が見る分類フォルダは日本語で統一します。
- プラグインやスキル自身の識別名は、動作互換性のため必要に応じて英数字を使います。
- 外部から導入したものは、取り込み元、ライセンス、変更点を記録します。
- 一つを修正したときに他へ影響しにくいよう、道具ごとに独立したフォルダで管理します。
- GitHubへ置いただけでは、各アプリへ自動的にインストールされません。導入手順は各道具のREADMEに記載します。

## 技術用ファイル

`.agents/plugins/marketplace.json` は、Codexがこのリポジトリ内のプラグインを見つけるためのマーケットプレイス定義です。
