# 道具の管理方法

## 新しい道具を追加するとき

- 一つの道具につき、一つの独立したフォルダを使います。
- その道具のREADMEを用意します。
- READMEには、目的、対象環境、使い方、導入方法、更新方法、取り外し方、制約を書きます。
- プラグインやスキルの機械的な識別名は、動作互換性を優先して必要に応じて英数字とハイフンを使います。
- 人が見る分類フォルダは、日本語で統一します。
- 外部から導入したものは、取り込み元、ライセンス、原形からの変更点を記録します。
- 既存の道具と役割や保存場所が重複していないか確認します。

道具は一つずつ独立したフォルダへ置くため、同じ種類の道具を横へ追加できます。

```text
OpenAI・Codex用/
└── プラグイン/
    ├── evidence-first/
    ├── 次のプラグイン/
    └── さらに別のプラグイン/
```

## 変更・取り外しをするとき

- 変更する道具のREADMEで、更新方法と影響範囲を確認します。
- リポジトリの保管物と、AI環境へインストール済みのものを区別します。
- 削除前に、利用中の場所、参照、影響、復旧方法を確認します。
- 取り外した後は、対象環境に残っていないか確認します。

## 情報を残す場所

| 内容 | 残す場所 |
|---|---|
| ツールセット全体の概要と現在の道具 | ルートのREADME |
| 確定した詳しい使い方や管理方法 | `説明書`フォルダ |
| 個別の道具の導入・更新・取り外し方 | 各道具のREADME |
| 特定のAI環境だけに関係する説明 | そのAI環境のフォルダ |
| まだ決まっていないアイデア、問題、検討事項 | Issue |

Issueを作るたびに、ルートのREADMEを更新する必要はありません。
